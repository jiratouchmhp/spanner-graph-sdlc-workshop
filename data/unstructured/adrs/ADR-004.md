# ADR-004: Tokenized Card Vault (`tok_pci_v2`) & 45ms Fail-Closed Fraud Gate

- **Status:** `ACCEPTED` (supersedes `ADR-001` as of `2024-09-12`)
- **Owner:** `team-payments` (`#payments-eng`)
- **Decision Date:** `2024-09-12`
- **Governed APIs:** `api-payments-charge-v2` (`MANDATES`), `api-payments-refund-v2` (`MANDATES`), `api-fraud-score-v1` (`MANDATES`), `api-fraud-rules-v2` (`MANDATES`), `api-checkout-submit-v1` (`CONSTRAINS`)

## Context

Under `ADR-001`, raw PAN payloads on `api-payments-charge-v1` expanded PCI-DSS 4.0 compliance scope across `svc-checkout` and `svc-billing`. Simultaneously, high-value card-testing attacks exposed the need for a deterministic, latency-bounded real-time risk gate before acquiring authorization.

## Decision

1. **Mandatory Card Tokenization (`REQ-001`):** `api-payments-charge-v2` (`POST /v2/payments/charge`) and `api-payments-refund-v2` MUST reject raw PAN numbers (HTTP `400 Bad Request`) and accept ONLY vaulted payment tokens strictly matching the format `tok_pci_v2_<32hex>` (a `tok_pci_v2_` prefix followed by 32 lowercase hexadecimal characters).
2. **45ms Synchronous Fraud Timeout Budget (`REQ-002`):** Before calling external card networks, `svc-payments` MUST synchronously invoke `svc-fraud` via `api-fraud-score-v1` and `api-fraud-rules-v2` within a strict `45ms` timeout budget so end-to-end `POST /v2/payments/charge` stays within its `180ms` p99 SLA.
3. **Fail-Closed Policy for Charges `> $500` (`REQ-003`):** If `api-fraud-score-v1` exceeds the `45ms` deadline or returns a transient error:
   - Transactions with `amount > $500` (USD equivalent) MUST **fail-closed** (reject with HTTP `503 Service Unavailable` / risk decline code `FRAUD_GATE_TIMEOUT`) and NEVER fall back to blind authorization.
   - Transactions `<= $500` may fall back to cached deterministic velocity rules (`api-fraud-rules-v2`) with mandatory async post-auth review alerts to `team-risk` (`#risk-fraud`).

## Consequences

- **Reduced PCI-DSS 4.0 Blast Radius:** `svc-checkout` (`team-checkout`) and `svc-billing` (`team-billing`) handle only `tok_pci_v2_<32hex>` tokens on v2 paths, isolating raw PAN custody to the PCI card vault.
- **Tight Coupling to `svc-fraud` Availability:** Any latency regression in `svc-fraud` above `45ms` immediately impacts conversion on high-value `> $500` orders across `svc-checkout`, `svc-orders`, and `svc-partner-gw`.
- **Legacy v1 Retirement:** Supersedes `ADR-001`; `team-billing` must finish migrating `svc-billing` off `api-payments-charge-v1` to close `REQ-004`.

# REQ-014: Cross-Region Spanner Backup DR Copy to Singapore (`asia-southeast1`)

- **Framework:** `DR_RPO_RTO`
- **Severity:** `HIGH`
- **Owner:** `team-billing` (`#billing-ledger`)
- **Applicable Services:** `svc-ledger` (`COMPLIANT`)
- **Related ADRs:** `ADR-008`

## Disaster Recovery Objective

While Cloud Spanner `regional-asia-southeast3` (Bangkok) provides `99.99%` availability across three synchronous zones (`asia-southeast3-a/b/c`) with zero-RPO single-zone failover, financial governance requires a cross-region disaster recovery posture protecting against full-region catastrophes.

## Cross-Region Backup & Failover Architecture

1. **Automated Cross-Region Backup Copy:** Production `svc-ledger` and core SDLC databases take automated scheduled Cloud Spanner backups in `asia-southeast3` and copy encrypted backups cross-region to Singapore (`regional-asia-southeast1`) via `gcloud spanner backups copy`.
2. **Optional Async Warm DR:** For workloads requiring `RPO <= 15m` and `RTO <= 60m`, Cloud Spanner Change Streams replicate committed mutations asynchronously via Dataflow to a passive Enterprise instance in `regional-asia-southeast1` (since no native dual-region config pairs `asia-southeast3` and `asia-southeast1`).
3. **Quarterly Restore Drills:** `team-billing` (`#billing-ledger`) executes quarterly restore verification drills in `asia-southeast1` validating `SUM(debits) == SUM(credits)` ledger parity (`REQ-005`).
